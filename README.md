One-sentence pitch for a ridiculous invention that fixes a tiny everyday annoyance: a toaster that ejects your bread with a tiny parachute, so it never lands butter-side down on your kitchen floor again.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Writes one sentence (119 characters) to `/output/entry.txt`. Deterministic: the same fixed sentence on every run, no randomness, no clock, no network.
